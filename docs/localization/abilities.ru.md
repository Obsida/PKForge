# Перевод способностей и характеров

`src/PKForge.App/Services/RussianAbilities.cs` содержит русские варианты названий и краткие описания всех 310 способностей закреплённой версии PKHeX. Это перевод для интерфейса, не официальный словарь локализации игр.

Ключ словаря — ID из таблицы `external/PKHeX/PKHeX.Core/Resources/text/other/en/text_Abilities_en.txt`. Английские имена сохраняются для поиска и сверки. Локализованные строки не записываются в игровые данные или экспорт Showdown. Неизвестные будущие способности сохраняют исходное название и описание.

Важные совпадения названий:

- ID 266 и 267 — разные варианты As One с повышением Атаки и Спецатаки соответственно.
- ID 301–304 в PKHeX — четыре варианта Embody Aspect: Скорость, Атака, Спецзащита, Защита.

Полные английские имена вариантов берутся в том виде, в котором их предоставляет `GameStrings` закреплённого движка, включая его суффиксы. Эффекты вариантов Огерпон привязаны к игровым ID из personal-таблицы: форма источника использует ID 303, форма очага — ID 302. Порядок ID в сторонних справочниках нельзя переносить напрямую.

У некоторых описаний PokeAPI в исходном `dexfacts.tsv.gz` неверное соответствие ID, в частности у Cotton Down и поздних способностей поколения 9. Перевод использует ID PKHeX; эти описания сверены с [реализацией способностей Pokémon Showdown](https://github.com/smogon/pokemon-showdown/blob/master/data/abilities.ts) и [его справочными описаниями](https://github.com/smogon/pokemon-showdown/blob/master/data/text/abilities.ts). Краткие русские формулировки составлены отдельно. Значения множителей и ограничения, зависящие от поколения, намеренно не выдаются за универсальное правило.

`RussianGameText.cs` содержит 25 характеров, подписи типов и вкусовые предпочтения для интерфейса. Числовые ID и расчёты характеристик остаются в движке.

Проверка: `RussianAbilitiesTests` сверяет все имена с таблицей движка, полноту покрытия, различные варианты одинаково названных способностей и сохранение неизвестных значений. `RussianGameTextTests` проверяет соответствие характеров их ID и английским ключам поиска.
