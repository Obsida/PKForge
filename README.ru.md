# PKForge RU для Windows

Локальный форк [sofianeelhor/PKForge](https://github.com/sofianeelhor/PKForge), исходная версия 3.1.1, коммит `2df04430e532b78c247f45b936f3068d8f824987`.
Изменения находятся в ветке `windows-russian`; оригинал подключён как Git remote `upstream`.

## Запуск

Открой `Start-PKForge.cmd` или `dist\windows-x64\PKForge.App.exe`.
Нужна Windows 10 версии 2004 или новее, x64. Сборка включает .NET и Windows App SDK.
Для переноса на другой компьютер скопируй **всю папку** `dist\windows-x64`.

Выбери **Открыть сохранение** для одного файла или **Подключить эмулятор** для поиска в папке.
Работают обычные игровые сохранения: `.sav`, `.srm`, `.dsv`, `.gci`, файлы `main` от 3DS/Switch и другие форматы исходного движка. Состояния эмулятора (save states) не поддерживаются. Для Dolphin нужен отдельный `.gci`, не образ всей карты памяти.
Перед редактированием сохрани игру и закрой эмулятор. После записи загрузи игру обычным способом.
Перед изменением игрового сохранения создаётся точка восстановления, доступная в настройках.
Удаление покемонов из **банка** необратимо: точки восстановления оригинала относятся к игровым сохранениям.

## Управление

- Мышь: левый щелчок — выбор; правый щелчок по игре — её меню.
- Стрелки — навигация.
- Enter — выбрать / подтвердить; Esc — назад / отмена.
- X и Y — действия, указанные внизу экрана.
- Page Up / Page Down — боксы и страницы.
- F10 — меню; F2 — множественный выбор.
- В выборе цветовой темы работают колёсико мыши и перетаскивание списка.

В текстовых полях клавиши редактируют текст обычным способом.
**Esc** возвращает на один шаг: из параметров создания — к форме или виду, затем к меню добавления и боксу. Из выбранного покемона — к боксу; повторное отдельное нажатие выходит из хранилища. Удержание Esc не закрывает несколько уровней подряд.
Удаление из игрового сохранения: выбери покемона → **X / Инструменты → Удалить покемона**. Этот же пункт есть в меню покемона (**F10**).
Для нескольких покемонов: **F2**, отметь нужных, затем **X → Удалить выбранных**. Требуется подтверждение; перед записью создаётся точка восстановления. Защита от выпуска также блокирует удаление.
Прямой ввод с контроллера, отдельное окно на втором дисплее и Android-виджет в Windows пока не реализованы.

## Изменения и перевод

В редакторе характеристик **Max IV** выставляет все шесть IV в 31 (для поколений 1–2: **Max DV**, 15). EV остаются прежними. Изменения записываются кнопкой **Сохранить изменения**.
При сохранении кнопка показывает **Сохранение…**, рядом отображается индикатор, а под кнопкой остаётся результат: сохранено, изменений нет или ошибка. Подготовка файла и его проверка выполняются в фоне.

Фоновая музыка: **Настройки → Музыка → Добавить музыку**. Встроенных треков нет; выбери свои аудиофайлы. Музыка продолжает играть при сворачивании окна, а Покепарк может использовать музыку меню либо свой список. Доступность отдельных форматов зависит от кодеков Windows.

В Windows Покепарк использует отрисовку без ANGLE: прежний графический слой приводил к вылету. Подсказки показывают клавиши ПК, значок батареи скрыт.

Окно создания покемона подстраивается под размер окна, в том числе при изменении размера: в узком окне карточка располагается над параметрами. Содержимое прокручивается, кнопки **Создать / Отмена** всегда видны.
В выборе **Добавить предмет** скрываются все предметы с ненулевым количеством в рюкзаке. Их количество меняется непосредственно в рюкзаке; после удаления предмет снова доступен для добавления.

Добавлены цель MAUI/WinUI для Windows, файловые диалоги, поиск во вложенных папках и запись через временный файл с заменой. Занятый файл не перезаписывается. Сохранены движок PKHeX, проверка легальности, банк и резервное копирование оригинала.

Словарь содержит 1682 перевода для главных меню, редактора, банка, импорта/экспорта, настроек и восстановления. Добавлен шрифт Noto Sans с кириллицей и лицензией OFL.
Добавлены русские названия и краткие описания **166 способностей**: все способности поколений 3–5 и часть более поздних, включая способности Милотика. Они видны в выборе способности, карточках и сводке покемона; в выборе работает поиск по исходному английскому названию. Словарь — `src/PKForge.App/Services/RussianAbilities.cs`; отсутствующие переводы показываются на английском.
Перевод **не полный**: названия видов, предметов, остальных способностей и приёмов из PKHeX, подробные отчёты движка, часть редких подсказок и историй Покепарка остаются на английском. Перевод интерфейса не переводит игровые сохранения и не добавляет играм поддержку кириллицы.
Обновления оригинального Android-приложения отключены, чтобы они не заменили форк.

## Сборка

Локальный SDK .NET 10 находится в `.tools\dotnet`. Глобальный SDK не заменялся.

```powershell
.\build-windows.ps1
```

На другом компьютере нужны .NET 10 SDK и `dotnet workload install maui-windows`. Зависимости: `git submodule update --init --recursive`.

```powershell
.\.tools\dotnet\dotnet.exe test tests\PKForge.Domain.Tests\PKForge.Domain.Tests.csproj -c Release
.\.tools\dotnet\dotnet.exe test tests\PKForge.Engine.Tests\PKForge.Engine.Tests.csproj -c Release
```

Android-исходники сохранены и содержат перевод. Для APK нужны `maui-android`, JDK и Android SDK; цель — `net10.0-android`. Готовый APK пока не собран.

Проверка реальных экранов Windows: `powershell -File tools\test-windows.ps1`. Диагностическая сборка хранит данные отдельно от основной программы. Проверяются события, Покепарк, прокрутка тем, Max IV с записью **копии** тестового сохранения, карточки подарков и аудиоплеер. Снимки окна и журналы сохраняются в `.tools\smoke`. Можно передать `-SavePath` с сохранением Pokémon X/Y; оригинальный файл не изменяется.
Дополнительная проверка хранилища: `powershell -File tools\test-windows.ps1 -Mode storage`. Проверяет индикацию сохранения, возврат по шагам, колесо мыши и отпускание полосы прокрутки, форму создания при изменении окна, перевод способности Милотика, фильтрацию предметов в настоящем списке добавления, отмену удаления и удаление с повторным открытием копии сохранения и точкой восстановления.

Словарь перевода — `tools\Localization\ru.tsv`. Утилита `tools\Localization` строит каталог строк и применяет точные переводы к интерфейсу C#. При переносе изменений оригинала проверяй обработчики меню, использующие текст кнопок. Пути привязки `Binding` переводить нельзя.
